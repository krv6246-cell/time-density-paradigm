# Ontology and core concepts

## Status

This is a concise editorial synthesis of the project vocabulary in `TimeDensity-Core/docs/concepts.md`. It describes a conceptual framework, not an established physical theory or a set of validated measurements.

## Working vocabulary

- **System:** an entity considered together with its context and conditions.
- **State:** a description of a system at a given point, including conditions and available possibilities.
- **Transition:** a change from one state to another.
- **Temporal context:** the project's way to discuss how temporal load, intensity, or perceived pressure relates to a process.
- **Time density:** a proposed project concept for characterizing that temporal context. The source material does not provide an operational definition or unit in the reviewed document.
- **Phase or mode:** a named regime used to describe a system's behavior.

These definitions organize the project's language. They do not establish that time is a physical substance or that density gradients cause gravity, matter, or cosmological observations.

## Claims that need further support

The source FAQ makes claims about gravity, the speed of light, and cosmology. They are not reproduced here as established findings: no supporting derivation, data, or peer-reviewed citations were identified in the reviewed files. Treat them as unverified model proposals unless such evidence is added and independently checked.

The equation `rho(x) = 1 - |x|` and a 300–500 ms perception delay are not included as established results. If project owners want to retain either as a model or illustrative value, document its source, variables, assumptions, scope, and limitations.
